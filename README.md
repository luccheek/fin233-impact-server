# FIN 233 impact lookup server (cloud copy)

Cloud fallback for the FIN 233 dashboard's stock search
(https://luccheek.github.io/fin233-dashboard/). Serves live pitch-impact
lookups for tickers outside the pre-baked universe. Code and the portfolio
base file are synced automatically by the nightly refresh job; do not edit
here. Educational use; not investment advice.
